Stock Ticker

A responsive, real-time stock ticker application built with vanilla JavaScript, HTML5, and CSS3. Designed to display live or simulated stock quotes, price fluctuations, and percentage changes with clear visual indicators and smooth layout adaptability.

Key Features
Live Quote & Price Change Display
Visual Gain/Loss Indicators
Dynamic Updates
Responsive Ticker Layout

Tech Stack

- HTML5: Semantic structure for ticker cards/strips, symbol labels, and price readouts.
- CSS3: Flexbox/Grid layout, responsive media queries, and gain/loss state styling.
- JavaScript (ES6+):DOM manipulation, number/percentage formatting, and interval-driven or event-driven UI updates.
